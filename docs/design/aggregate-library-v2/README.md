# 聚合媒体库 V2：存储、文件源与入库范围

状态：已接入 iOS 业务模型与界面；构建、安装和验证记录见文末实施说明。

## 1. 核心定义

**存储是连接和访问权限；文件源是要入库的目录；聚合媒体库是所有启用文件源的扫描结果。**

```
家庭 NAS（SMB / Media 共享）             115 个人网盘
  ├─ /电影/华语 →「华语电影」文件源       └─ /纪录片 →「自然纪录片」文件源
  └─ /电视剧   →「我的剧集」文件源
                         ↓
                 扫描、识别、合并版本
                         ↓
               唯一的「聚合媒体库」
```

- 添加存储只建立连接，不自动扫描整盘、不自动加入媒体库。
- 一个存储可提供多个文件源；一个文件源对应一个选定目录，并递归包含其子目录。
- **多选三个目录，生成三个独立文件源**，导入前逐个命名，一次确认。这样可以分别禁用、扫描和删除。
- 同一存储中允许导入根目录；根目录没有自然名称时，默认名称为「存储名称 · 全部视频」。
- 文件源名称是 Lucent 中的显示名称，不修改存储目录名。
- 影视服务器仍是独立分类，直接使用服务器元数据；不变成存储，也不进入本地刮削流程。

## 2. 页面结构

### 2.1 片源 → 聚合媒体库：日常管理

从上到下：

1. 固定页面标题「片源」及右上角统一加号。
2. 保留外层「影视服务器 / 聚合媒体库」切换。
3. 紧凑统计卡：电影 **部数**、剧集 **部数**、视频 **文件数**；底行显示最近完成扫描时间和待处理任务。未匹配视频只计文件，不计电影。
4. 「存储」入口：显示已添加数量、异常数量，点按进入存储列表。此处没有入库开关。
5. 「文件源」标题、数量和「导入」按钮。
6. 已导入文件源的目录列表。
7. 保留现有底部 Tab 与独立搜索入口，避免在片源页新增另一个搜索服务器框。

统计卡只展示汇总，不设置第二个“媒体库管理”跳转。全局刮削、自动扫描、缓存配置仍在设置 → 聚合媒体库。

**文件源每行：**

- 左侧：目录图标，网络来源的标识放在图标角标或次要文字中。
- 第一行：自定义名称，最多两行。
- 第二行：存储名称 · 目录路径。长路径尾部优先展示，可在管理弹窗查看全文。
- 第三行：视频数量 · 最近扫描，或「扫描中 128 / 920」「需要重新授权」「已禁用」。
- 右侧：启用开关，语义为「加入聚合媒体库」。
- 点按行主体：浏览该文件源所对应的目录。
- 长按：重新扫描、启用/禁用、重命名、查看来源、移除。禁用时重新扫描入口不可用，启用后恢复。
- VoiceOver 提供相同的自定义操作，不依赖长按才能操作。
- 标题区的更多菜单可进入多选模式，批量扫描、启用/禁用、移除；重命名仍逐个处理。

### 2.2 存储列表：连接管理

采用原生大标题与分组目录卡，按“本地、网络共享、网盘、局域网设备”分类。

每个存储显示名称、协议/服务、账户或根目录、连接状态、引用的文件源数量。

- 点按：进入目录浏览。
- 长按：编辑名称和连接、重新连接/授权、移除。
- 右上角加号：添加存储。
- 这里没有入库开关，没有“扫描整台 NAS”按钮。
- 连接状态基于实际验证；未检查时显示「尚未检查」，不默认显示绿色在线。
- 连接失败时只影响该存储的操作；已入库内容保留，并提示当前不可访问。

### 2.3 添加存储

类型：本地文件夹、SMB 共享、WebDAV、网盘、DLNA。

流程：选择类型 → 输入连接或授权 → 验证连接 → 保存存储。

成功后提供「选择目录」和「稍后」两个操作。选择稍后也会保留存储。

- 本地文件夹：系统目录选择器获得授权的文件夹就是可访问根；不能假设能浏览 iPhone 任意目录。
- SMB：存储定义为“账户 + 共享根”，例如 NAS 的 Media 共享。同一 NAS 的另一共享可添加为另一个存储。
- WebDAV：授权账户及配置的根 URL 构成访问根，保持子路径边界。
- 网盘：显示服务与账户，授权后按真实文件夹 ID 浏览，不能把递归扫描后的视频文件名当成目录树。
- DLNA：发现或手动添加设备；读取 ContentDirectory，从容器树中选择范围。目录持久化使用设备标识与 ObjectID，不使用会过期的媒体 URL。

切换网盘类型必须清除前一个服务的授权草稿；修改账户视为新存储身份，不能让旧文件源悄悄指向另一个人的文件。

## 3. 导入文件源的完整流程

### A. 选择存储

点「导入」后，底部选择器列出已添加存储；最后有「添加存储」。无需退回列表完成新连接。

无存储时显示专用空态：说明“先连接存储，再选择要入库的目录”，主按钮「添加存储」。

### B. 浏览并多选目录

全屏导航页面：

- 标题「选择目录」，副标题为存储名称。
- 路径面包屑可返回上级；层级长时保留根与最近层级。
- 行左侧为选择框，点击选择框选中；点击目录名称进入下一级。两种操作分开，避免选择时意外进入目录。
- 只允许选择目录；普通视频可以作为浏览内容出现，但不提供目录选择框。
- 底部提供「选择当前目录」，支持选择存储根。
- 多选状态跨层级保留；底部固定显示「已选 N 个目录」、查看已选、下一步。
- 当前目录搜索只检索当前已加载目录；不承诺一次搜索整个网盘。
- 已导入目录显示「已导入」及对应文件源名称，可定位该文件源，不重复添加。
- 下一步在没有有效选择时禁用。

**重叠目录规则：**

- 选择父目录后，其下级目录显示「已包含」，不再重复选择。
- 已选子目录时再选择父目录：用父目录替换子目录选择，并给出明确提示。
- 已导入的父目录已覆盖当前子目录：提示「已由『某文件源』覆盖」，默认不允许重复导入。
- 已有子目录文件源时导入父目录：显示冲突文件源名称，默认阻止重叠导入，并提供定位现有文件源入口。需要扩大范围时，先移除原文件源再导入父目录；稳定文件身份会保留续播记录。
- 首版不引入隐式排除目录或自动合并文件源，避免用户禁用一个文件源后，其内容又被父目录重新加入。

### C. 命名并确认

固定标题「导入文件源」，列表中每个选中目录对应一个命名项：

- 存储名称、完整目录路径。
- 可编辑的文件源名称，默认目录名称。
- 从本次批次移除该项。

底部选项：**导入后立即扫描**，默认打开。

主按钮「导入 N 个文件源」。空名称在行内提示；重名允许，但用存储与路径区分。相同存储的相同目录不允许重复。

保存是原子操作：先全部保存导入关系，再异步入扫描队列。保存失败保留选择和名称，支持重试；扫描失败不撤销已导入的文件源。

关闭立即扫描时：文件源保持启用、状态为「尚未扫描」，可稍后单独扫描；不把“暂不扫描”偷换为“禁用”。

### D. 返回概览

立即返回聚合媒体库，显示新增行及排队状态。大型目录不占住整个导入页面等待扫描完成。

## 4. 操作语义

| 操作 | 文件源 | 存储连接 | 原文件 | 媒体库与记录 |
|---|---|---|---|---|
| 重命名文件源 | 改显示名称 | 保留 | 不改名 | 影片身份、进度不变 |
| 禁用文件源 | 保留，暂停入库贡献 | 保留，可继续浏览 | 不变 | 从聚合结果隐藏；其他启用来源仍可贡献同一影片 |
| 重新扫描 | 只处理所选范围 | 保留 | 只读 | 增量同步新增/变动/确认删除的文件 |
| 移除文件源 | 删除导入关系 | 保留 | 不删除 | 没有其他来源贡献的内容移出聚合库；进度、下载按各自身份保留 |
| 重命名存储 | 引用关系不变 | 改显示名 | 不变 | 所有文件源立即显示新存储名 |
| 修改连接凭据 | 文件源 ID 不变 | 同账户可更新 | 不变 | 重新验证后恢复访问 |
| 修改存储账户 | 不静默重绑 | 新建存储身份 | 不变 | 原文件源保留原身份，需用户重新选择范围 |
| 移除存储 | 显示将受影响的 N 个文件源 | 删除连接与凭据 | 不删除 | 确认后一起移除关联文件源及入库贡献 |

移除文件源确认文案：“从聚合媒体库移除『华语电影』？存储连接和原始文件会保留。”

移除存储确认文案：“移除『家庭 NAS』及其 3 个文件源？这些内容将退出聚合媒体库，原始文件不会删除。”

离线、超时、授权失效、扫描取消都不等于目录为空，不得因此把所有影片标记为已删除。

## 5. 状态与扫描

三个维度独立：

- 存储连接：未验证 / 连接中 / 可访问 / 离线 / 需授权。
- 文件源启用：启用 / 禁用。
- 扫描任务：未扫描 / 排队 / 枚举目录 / 匹配资料 / 完成 / 部分失败 / 已取消。

展示优先级：需授权、扫描中、部分失败、禁用、最近扫描；行内仍保留可查看全部状态的入口。

扫描分两段：先枚举并持久化文件索引，再异步匹配元数据。能先看到已识别内容，不等待整个文件源全部刮削。

- 同一个存储默认最多一个枚举任务；不同存储默认最多两个并行任务，避免网盘限流及 NAS 连接风暴。
- 元数据匹配使用独立、有限并发队列，并复用本地缓存和相同影片匹配结果。
- 支持取消任务、仅重试失败项；后台被系统中断后标记“等待继续”，下一次前台恢复，不声称 iOS 能持续无限扫描。
- 扫描期间禁用：取消该源尚未完成的任务，已完成索引保留；任务回调必须核对 sourceID 和任务代次，防止旧任务重新入库。
- 删除文件源期间：取消任务、删除成员关系，过期回调不能重建来源。
- 只有完整成功枚举的目录范围才能据此判定远端文件已移除；部分失败保留原索引。

## 6. 数据模型与身份

### StorageConnection

`id, kind, displayName, endpoint, accountIdentity, credentialReference, rootLocator, capabilities, lastValidatedAt`

- 凭据仅通过 Keychain 引用；模型、日志和扫描记录不保存签名 URL。
- 本地 rootLocator 是安全书签；SMB 是共享根；WebDAV 是根 URL；网盘是根文件夹 ID；DLNA 是设备标识 + 容器 ID。

### LibraryFileSource

`id, storageID, directoryLocator, displayName, enabled, recursive=true, createdAt, lastSuccessfulScanAt`

目录身份使用存储原生标识，不以显示名称当主键。名称和路径展示值可以更新，身份应保持稳定。

### StoredMediaFile 与 SourceMembership

文件身份与“来自哪个文件源”分开。`StoredMediaFile` 保存实际存储文件身份、相对路径/资源 ID、大小、修改版本和媒体轨道；`SourceMembership` 记录文件属于哪些文件源。

- 同一物理文件只存一份索引，避免重叠范围重复播放记录、重复下载和重复刮削。
- 删除一个文件源只删除相应成员关系，不误删仍被其他文件源引用的条目和资源。
- 不同存储的同片文件仍分别保存；聚合展示可按 TMDB 身份合并为多版本。
- 剧集键包括剧 ID、季号和集号；不能只按同名影片合并。
- 观看记录仍按现有观看用户隔离；名称修改、禁用和重新导入不应改变文件身份。
- 下载属于下载管理，禁用来源不删除已下载文件。

## 7. 当前代码需要的重构

当前 FolderSource/SMBSource/WebDAVSource/CloudSource 同时承担连接和文件源职责，扫描接口大多从连接根开始。需要真正拆分，不能仅将页面文案改为“存储”。

| 当前情况 | V2 必需变化 |
|---|---|
| MediaLocation 使用 sourceID 直接查连接 | 文件改用 storageID；文件源通过成员关系决定是否入库 |
| 同一来源只有一个 included 开关 | enabled 移到 LibraryFileSource，每个导入目录独立控制 |
| scanSMB/scanWebDAV 扫描整个根 | 扫描接口接收 directoryLocator 和分页/检查点 |
| 网盘接口返回扁平 id/name | 增加逐级 listChildren、父 ID、文件夹类型和稳定目录标识 |
| DLNA Video 只保留标题和 URL | 保留 DIDL ObjectID、父容器及资源选择；按容器导入 |
| 文件源移除会清除整个连接的条目 | 改为取消任务、移除成员关系，再清理不再被引用的入库贡献 |
| 本地文件夹连接即一个文件源 | 书签作为存储根；子目录可单独导入；权限失效时重新绑定根 |

## 8. 旧数据迁移

1. 迁移前保留旧数据库副本，事务提交前旧表保持可回退。
2. 每个旧连接转换成一个存储，保留凭据引用与旧身份映射。
3. 旧版已加入媒体库的连接，为其根目录生成一个同名文件源；旧版仅浏览连接只迁移存储，不凭空导入根目录。
4. 对有明确导入历史的已禁用来源，迁移为禁用文件源。旧数据无法区分“仅浏览”和“曾入库后禁用”时，保留旧范围为待确认的禁用兼容记录，不自动开启；提供恢复文件源或仅保留存储的选择。不能仅凭存在播放条目就认定用户导入过整个根目录。进度和下载关联均保留。
5. 同服务器不同账户绝不合并；确认为同一账户/同一访问根的连接才可合并。网盘无法确认账户身份时保留独立存储。
6. 旧文件位置先通过映射读取并渐进转换，不重新生成 MediaItem UUID、不清空观看进度、不强制全盘重扫。
7. 网盘或 DLNA 旧数据缺少目录身份时，保留“原导入范围”兼容记录；提示重新选择范围后再切换新扫描器，不猜测文件夹结构。
8. 迁移完成后对账：源数量、文件数、影片身份、禁用状态、凭据可读取性及下载可访问性；失败回滚。

## 9. 视觉规范

- 默认深色，跟随现有系统/浅色设置；背景、文字、边框使用语义色。
- 原生导航栏、分段控件、菜单与底部弹窗；iOS 26 原生玻璃主要用于浮动操作区，内容列表保持稳定对比，不每行叠加模糊。
- 不额外叠加自绘返回按钮与系统工具栏背景。
- 页面左右 20pt，组间 24pt；行内 14–16pt。名称 17pt，路径/状态 12–13pt，图标 20–22pt，操作热区不小于 44pt。
- 目录多选使用清楚的选择框；启用开关保留高对比系统激活色，选中目录用中性强调，不以绿色文字代替选中状态。
- 导入按钮固定在底部安全区；键盘弹起时让命名项和按钮可达，已输入名称不因返回上一步丢失。
- 支持动态字体、VoiceOver、减少动态效果；动画仅用于页面推进、选择托盘展开和状态变化。

## 10. 实施顺序与验收

1. 连接/范围/成员关系模型和迁移，先验证已有账户、进度、下载不丢失。
2. 本地、SMB、WebDAV 的目录浏览、跨层多选、批量命名导入和范围扫描。
3. 网盘 listChildren 与 DLNA 容器树；接口能力不齐时明确标记，不用扁平视频索引冒充目录选择。
4. 扫描队列、失败重试、禁用与删除竞态处理。
5. 替换聚合概览及存储页面，完成深浅色和无障碍检查。

关键验收：一个 NAS 连接导入两个目录能独立管理；跨层多选不会丢选择；同路径不重复导入；禁用仅隐藏入库贡献；离线不会清空影片；删除文件源后存储仍在；移除存储会列出受影响范围；重命名不影响续播；旧数据迁移不跨账户串联。

## 设计预览

`prototype.html` 是可点击的静态设计稿，使用演示数据，可演示存储管理、目录多选、批量命名导入及文件源操作；不连接设备或服务，不修改应用数据。业务实现仍以上述方案为准。


## 实施说明（2026-10-28）

- 新增 `LibraryFileSource` 持久模型，连接仍保留原 ID 与钥匙串引用，播放位置不随文件源改名改变。
- 聚合页改为统计、存储入口及目录文件源；存储页分组管理本地、SMB、WebDAV、网盘、DLNA。
- 导入支持真实目录浏览、跨层级多选、父子范围排重、批量命名；目录命名不会修改存储中的名称。自动刮削以 30 项为一批串行消费待匹配队列，网络错误时停止，避免批量导入只处理前 30 个文件。
- SQLite 配置扩展保存文件源及其媒体关联、原生文件 ID 映射和未完成的扫描队列。导入事务失败回滚，重启后恢复未完成扫描。
- 扫描同一存储串行、最多两个存储并行；先完整遍历成功再批量协调索引。失败或取消不删除/判失效旧媒体；成功完整扫描才记录缺失。
- 禁用与移除文件源保留索引、观看记录和下载。移除存储同时取消相关任务、移除文件源及钥匙串凭据，原始文件保留。
- 旧启用连接迁移为根目录文件源；旧排除配置迁移为停用且待确认，避免自动扩大扫描。根目录范围需要调整时，移除该文件源后重新选择子目录，存储不受影响。
- 电影/剧集数统计已经匹配的项目，视频文件数包含待匹配文件。全局扫描和匹配继续位于设置模块。自动扫描支持仅手动/每天/每周（默认每天），回到前台仅检查已到期文件源，避免每次切换页面重新枚举整盘。
