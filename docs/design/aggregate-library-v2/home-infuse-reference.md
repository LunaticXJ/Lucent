# 聚合媒体库首页调整（6027）

## 参考与取舍

参考 Firecore 的 [Infuse 官方介绍](https://firecore.com/infuse) 与 [8.4 首页收藏栏目说明](https://firecore.com/blog/infuse-84-extras-intros-and-favorites)，采用分类入口、横向内容栏目、独立完整网格的浏览层级。不复制其品牌、素材或商业代码，继续使用 Lucent 原生 SwiftUI、详情页、图片缓存和底部导航。

## 首页

- 移除占据首屏的大海报、全量平铺网格及“海报墙”工具栏。
- 标题后依次展示继续观看、媒体库分类、最近添加的电影、最近添加的剧集、收藏。
- 分类包含电影、剧集、收藏及其他视频。分类数量用于内容导航，不展示扫描/刮削统计。
- 继续观看使用 16:9 图片，进度条收在图片底部；海报栏目为 2:3 竖图，标题两行固定高度，年份统一对齐。
- 普通首页海报不堆叠评分、版本数和集数徽标，减少视觉噪声。
- 每栏提供“查看全部”，进入独立自适应网格，可按名称、最近添加、年份或评分排序，并按题材、观看状态筛选。
- 右上角菜单可选择显示哪些首页栏目，选项持久保存；不增加第二套搜索控件。
- 分类页保留底部 Tab，隐藏首页片源浮层。影片详情沿用原生返回与 hero 过渡。

## 管理信息归属

首页代码不读取/显示刮削状态、探测状态、重试按钮或待匹配列表。文件源扫描、刮削、探测进度继续放在片源 → 聚合媒体库；全局重试、令牌和手动匹配入口继续放在设置 → 聚合媒体库。其他视频可从分类浏览，并在单条内容的菜单里匹配资料。

## 分类一致性

- 整部剧最近添加时间取各集最新入库时间，避免代表集较老导致整剧不更新排序。
- 某一集被收藏时，其剧集可从收藏分类找到。
- 尚有未观看集的剧不会因为看过其中一集而被当成整剧已观看；电影多版本按任一版本完成观看归类。

## 6034：指定的七类首页与栏目入口

用户改为要求对齐现有 Emby 首页；当前由 `MobileHomeView` 共用轮播、分类卡片、海报栏目，而非本文件早期的独立 Infuse 首页。

- “继续观看”整个标题行（含右侧数量和箭头）可点击：聚合媒体库进入完整续播集合，Emby 进入单独的续播列表，不再跳到普通根目录。
- “我的媒体”同样可点击：聚合媒体库进入七类总览，Emby 进入服务器根目录。
- 固定七类顺序：电影、国产剧、综艺、国漫、日韩剧、欧美剧、纪录片。分类卡片即使暂无内容仍保留；下方仅对非空分类展示最近入库横向海报栏目，标题直接使用分类名称。
- 同组剧集按最近一集的入库时间排序。复用各分类海报墙与筛选；总览保留“全部影片”以访问暂无可靠细分类的已匹配内容。
- 分类优先使用明确的分类目录（不读取文件名中的分类词），随后使用 TMDB 题材 ID、国家地区、原始语言；旧资料后台补齐 `genre_ids`、`origin_country`/`production_countries`、`original_language`，空国家数组是合法已读取值。
- 参考 MoviePilot `app/modules/themoviedb/category.py` 的题材、国家、语言分类条件设计（https://github.com/jxxghp/MoviePilot/blob/v2/app/modules/themoviedb/category.py）。Lucent 使用用户指定的固定分类、目录优先与本地 Swift 实现；没有复制上游实现，也没有新增 YAML 分类配置。
- 离线检查覆盖七类、目录优先、题材与国家判定、未知产地不猜测；界面由用户手动验证。
