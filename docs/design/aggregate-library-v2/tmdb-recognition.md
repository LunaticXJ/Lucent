# TMDB 识别规则对齐（6030）

## 参考与边界

用户要求借鉴算法设计并对齐功能。参考 MoviePilot v2，固定提交 `1528176beacc0f9f8d8d9cbf1adf048b0da67b5c`：

- `app/modules/themoviedb/tmdbapi.py`：候选排序、两轮名称比较、季年份、年份尝试顺序、混合搜索。
- `app/modules/themoviedb/__init__.py`：搜索词顺序、类型/年份回退、指定 ID 的命名空间消歧。
- `app/utils/string.py`：比较时忽略的标点、空白、零宽字符。
- `app/core/metainfo.py`：文件/目录显式 ID 提示设计。

上游为 GPL-3.0。Lucent 依照行为规则独立编写 Swift，实现中不包含 Python 源码、Python 运行时或 MoviePilot 依赖。对照测试可从外部上游文件中动态执行方法，测试参考源码不打包进 App。

本次范围是 TMDB 识别链路。MoviePilot 的下载、订阅、站点插件、豆瓣/Bangumi/其他识别源、完整自定义识别词库与 NFO 文件采集不属于此 TMDB 算法模块；Lucent 当前没有实现这些功能。本次不能宣称整个 MoviePilot 功能等同，也不能用有限测试声称所有文件输入均已证明一致。

## 已对齐的识别规则

| 输入/阶段 | Swift 行为 |
| --- | --- |
| 名称输入 | 中文名、简体中文名、英文名按序去重；标题清理保留年份独立提示 |
| 名称比较 | 大写比较，去标点、空白与零宽字符，不以模糊分数猜片 |
| 明确 TMDB ID | 优先查 ID；未知类型查 movie/tv 两个命名空间，以标题（含别名）与年份评分消歧，相同分数保持未匹配 |
| IMDb ID | `/find` 解析，失败后进入名称识别（补充 Jellyfin 的外部 ID 设计） |
| 年份 | 原年份、后一年、前一年依次尝试 |
| 普通候选 | 日期降序，同名取第一个；先比较所有候选的标题/原名，再取详情比较别名/翻译 |
| 已知剧集 | 先检查标题+首播年，随后详情中的当前季年份；再走普通年份分支；最后去掉年份，仅查 TV |
| 未知类型且无年份 | multi 搜索，电影优先于剧集，各类型内部日期降序 |
| 其他类型/有年份 | 电影→剧集→不限年份的 multi |
| 多个搜索词 | 对每个搜索词完整执行以上流程后再尝试下一个词 |
| 剧集组 | 使用组内季号/顺序检查季年份，单集资料请求前映射到原始季集坐标 |
| 别名数据 | 详情请求附带 `alternative_titles,translations`，同时支持电影 titles 和剧集 results 结构 |

## Lucent 的运行时集成

- `TMDBCatalogRecognizer` 为串行 actor；按搜索词/类型/年份缓存响应，按类型+ID 缓存详情，按输入缓存正/负识别结果。一批最多 30 个文件，同一节目多集共享查询。
- 资料缓存的 key 从片名改为类型+ID，避免 movie/tv 同号碰撞。
- 文件目录显示路径保存在 `MediaItem.catalogPath`，网盘原生 ID 继续用于访问，目录命名提示不丢失。已有文件从原路径/身份恢复提示，不要求重新导入。
- 自动匹配成功后持久化类型；未知文件识别成 TV 时更新为剧集身份。没有具体集号的条目不反复排队请求第 0 集。
- 网络错误、401/403、429、取消与“所有匹配分支未找到”分开处理；网络失败不写负匹配缓存。显式 ID 不会因请求失败而悄悄改成另一个片名。
- 保存手动匹配时，运行中的自动请求不得覆盖新身份；文件源被删除或停用时不提交旧请求结果。
- 手动重试清除匹配冷却期；主线程只更新状态、持久化，不执行 HTTP；FFmpeg 仍由独立开关控制，默认关闭。
- 中文数字季集、S00 特别季、S02 季目录、纯数字集文件、目录 TMDB ID 标签已接入文件名解析。MoviePilot 完整命名语法、识别词库和所有动画命名变体尚未逐项证明等价。

## 验证

`python3 scripts/verify-tmdb-recognition.py`：使用实际生产 Swift 模型/识别 actor，注入离线数据，覆盖 13 组行为，包括错误、缓存、年份、名称、季集、ID 与 80 文件去重，以及扩展解析用例。

`python3 scripts/verify-tmdb-recognition.py /path/to/reference`：目录中放固定提交的 `tmdbapi.py`、`string.py`。动态执行上游原始方法，对同样的 6 组候选数据比较最终 ID（年份容差、同名取新、标题优先、别名、季年份、混合类型）。不启动 Lucent，不访问用户媒体或网络。

`python3 scripts/verify-local-catalog.py`：本地资料/旧存档解码回归。

构建安装与离线匹配测试不能替代真实 TMDB 返回和真实媒体目录的手动验证。安装后需用户在设置中“重试刮削”，确认《我们的歌》《我想和你唱》的海报、季与单集归属。
