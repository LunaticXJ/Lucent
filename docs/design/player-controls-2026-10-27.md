# 播放控制与设置界面调整

## 参考范围

- [Forward 官网](https://forwardplayer.com/)：阅读公开页面和展示图，参考简洁的浮动控制分组和深色材质。
- [SenPlayer 官方商店截图](https://apps.apple.com/cn/app/id6443975850)：结合用户此前给出的横屏截图，保留顶部标题、底部中央播放控制和独立选集浮层。
- [VidHub 播放界面说明及配图](https://zh.vidhub.okaapps.com/video-playback/)：参考音轨、字幕、视频设置的分类、右侧设置面板与直接操作入口。
- Sodalite `31799bd` 的 `PlayerOverlayView.swift`、`PlayerTrackDropdown.swift`：研究独立的控制层、当前轨道标记、56pt 轨道行与滚动列表。其许可证是 GPLv3 加 Apple Store / DRM 例外；此次只参考交互设计，没有复制实现代码。
- [Apple glassEffect](https://developer.apple.com/documentation/swiftui/view/glasseffect(_:in:))：使用 SwiftUI 系统材质，而不是叠加多个自制模糊背景。

这些公开截图不是三个产品所有现行版本的完整界面审计；Lucent 根据现有功能重新组织控件。

## 布局和样式

| 项目 | 规则 |
| --- | --- |
| 播放外观 | 始终深色，主文字和图标白色，辅助文字白色 64% |
| 主控制 | 44pt 点击区域；中央播放按钮 68 × 48pt |
| 底栏 | 左侧选集及倍速、中间快退/播放/快进、右侧音轨/字幕/设置 |
| 标题 | 剧名和季集信息分两行；预留两侧工具空间 |
| 材质 | iOS/tvOS/macOS 26 使用 `.glassEffect(.regular)`；旧系统回退原生 Material |
| 减少透明度 | 回退到实色深灰背景，保留边界 |
| 面板 | 一个玻璃背景，26pt 圆角；内部选项使用轻量填充，避免多层玻璃叠加 |
| 轨道行 | 至少 58pt；选中项有白色实心勾、浅灰填充及“当前使用”标记 |
| 选中颜色 | 中性白灰，不使用绿色选择文字 |
| 抽屉 | 右侧进入，遮住一级控件；关闭或选择内核后恢复控制层 |
| 倍速 | 六档网格，当前项高亮；选择后关闭面板 |
| 进度条 | 正常 4pt、拖动 6pt，圆形拖动点，保留时间及可用预览图 |

音轨和字幕分别有底栏快捷入口，进入同一面板中的对应分段。没有可用轨道时显示相应空状态，独立字幕仍显示加载提示。关闭字幕与轨道选中状态联动；独立字幕异步请求继续在成功后提交选择。

播放设置分为内核、播放、画面、内容和高级选项。章节、播放列表、字幕延迟、外挂字幕开关与文本字幕样式仍可操作。显式服务器转码置于高级选项，并说明数值为请求上限、依赖服务器权限，不把固定码率描述为服务器返回的多路片源。

播放信息页改为可滚动的分组信息卡，删除横屏下不合适的 470pt 最小高度。音频路由 UIKit 按钮显式使用白色，避免系统蓝色图标混入控制栏。

## 应用设置

首页为三个分组，详细设置通过原生 NavigationLink 打开：

- 观看体验：外观与首页、播放、字幕。
- 内容与存储：聚合媒体库、缓存与存储、在线元数据。
- 账户与同步：观看资料、iCloud 与 Trakt。

长设置列表采用原生 Form 的语义颜色和分组容器；顶部导航由系统管理。保留跟随系统/深色/浅色主题、媒体库扫描和匹配、TMDB 令牌保存、资料管理、缓存与同步功能。列表文字和图标使用 primary/secondary，避免硬编码白色破坏浅色主题。

新增且接入播放器的设置：

| 存储键 | 默认值 | 控制内容 |
| --- | --- | --- |
| lucent.player.controlsAutoHideDelay | 3 秒 | 3/5/8 秒或不自动隐藏 |
| lucent.player.seekInterval | 10 秒 | 快进退按钮和无障碍进度调整，支持 5/10/15/30 秒 |
| lucent.player.showRemainingTime | false | 进度右侧显示总时长或剩余时长；也可点时间切换 |

字幕字号和底色继续作用于 Lucent 的文本字幕层；保留片源特效字幕的原始样式，界面说明了适用范围。AVPlayer 暂停时修改倍速只记录下一次播放速度，不因设置操作恢复播放。
