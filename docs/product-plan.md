# Lucent 产品与功能规划

更新：2026-10-16

更完整的竞品差距、优先级和发布门槛见[对标 Infuse 路线图](infuse-gap-roadmap.md)。

## 产品定位

面向拥有本地视频、NAS 或自建媒体库的用户，提供统一的媒体库与跨 Apple 设备播放体验。核心路径是「添加片源 → 扫描识别 → 找到影片 → 播放与续播」。不提供影视内容或资源搜索服务。

## 平台与首版范围

目标平台：iPhone、iPad、Apple TV、Mac。四端共用领域模型和播放状态定义，导航与交互按触屏、遥控器、键鼠分别设计。先实现可用的四端基础流程，再打磨高级能力。

### P0：可用的首版

1. 片源：iPhone/iPad/Mac 从系统文件选择器添加文件或文件夹；四端连接 SMB 共享目录。保存片源配置、重连与明确的错误提示。Apple TV 以网络片源为主要入口。
2. 扫描：递归发现视频文件，启动/返回前台及手动触发增量更新；依据文件名解析影片、剧集、季与集；允许手动修正识别结果。离线片源保留索引，原文件保持只读。
3. 媒体库：首页「继续观看」「最近添加」，电影/剧集分组，搜索、排序与详情页；海报、简介及手动匹配纳入首版。元数据服务失败时仍能浏览与播放文件。
4. 播放：播放、暂停、拖动进度、快进/快退、切换内嵌音轨及字幕、加载同目录外挂字幕、播放速度、记住播放进度和已看状态。控制器适配 Siri Remote、触摸和键盘。
5. 账户与隐私：无账户也能使用；片源凭据存入系统 Keychain；元数据请求由用户启用并说明会发送哪些影片信息。

### P1：体验增强

- Jellyfin 与 Plex 连接器，先支持直连浏览、播放和观看状态回写。
- WebDAV 片源、UPnP/DLNA 发现；更多文件名规则和批量修正。
- 字幕样式、音画同步调整、章节、片头片尾跳过标记、画中画与 AirPlay（按平台能力）。
- iCloud 同步观看进度、已看状态和手动元数据修正；冲突以最近一次明确操作为优先，并保留本地离线记录。
- 下载至设备（仅适用平台）、网络环境提示、缓存控制。

### P2：进一步扩展

- Emby 连接器、更多网络协议和云盘、多用户配置、Trakt 等第三方同步。
- 更广的格式和复杂字幕支持，以实测与版权/许可证评估为前提。

## 明确暂缓

首版不做账号服务器、在线视频聚合、转码服务器、DRM 破解、媒体文件编辑。4K/HDR、Dolby Vision、Atmos 等能力不作统一承诺，按设备、系统和实际文件组合验证。

## 关键用户流程与验收

| 流程 | 首版验收标准 |
| --- | --- |
| 添加片源 | 用户能在四端添加 SMB 片源并验证连接；连接失败可区分认证、网络与路径问题。 |
| 扫描识别 | 一个含电影与剧集的测试目录可生成媒体库；重复扫描不产生重复条目；离线片源保留索引并显示离线状态。 |
| 播放 | 从媒体详情进入播放，能选择可用音轨/字幕、拖动进度；播放中断后可续播。 |
| 手动纠错 | 识别错误的文件可手动修改标题/类型，重新扫描后修正仍保留。 |
| 平台操作 | Apple TV 全流程可仅用遥控器完成；iPhone/iPad 支持触控；Mac 支持键盘与窗口缩放。 |

## 建议开发顺序

1. **阶段 A：技术验证**。用真实样本测试播放格式、SMB 读取、字幕与四端基础播放；产出能力矩阵和内核决策。
2. **阶段 B：垂直切片**。四端完成「连接 SMB → 列表 → 播放 → 续播」，界面先简化。
3. **阶段 C：媒体库**。增量扫描、电影/剧集识别、搜索、详情、手动纠错及可选元数据。
4. **阶段 D：首版打磨**。离线/重连、凭据管理、遥控器与无障碍操作、性能和真实设备回归。

每阶段以可运行的应用和对应验收场景结束；阶段 A 的结果允许调整播放内核与 SMB 实现。
