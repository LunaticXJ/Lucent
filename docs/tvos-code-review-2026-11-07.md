- 已在 `Lucent Apple TV 4K / tvOS 27.2` 配置用户提供的 TMDB、Emby 与 WebDAV，凭据保存在应用的系统钥匙串。未迁移真机整库、收藏或观看记录；Emby 首页的继续观看来自服务器。
- iPhone 解锁后开发镜像个性化校验仍失败（CoreDevice 12051 / TatsuError 5），未成功附加调试器或读取真机配置。随后改用用户直接提供的三项配置。

- 一次性配置导入代码已从源码移除，临时凭据输入文件已消费并删除；不得将任何配置值写入仓库。

运行复现和本轮修改：

1. 语言设置的默认选择器确认后出现空白内容区。单独改为菜单样式后，表单字段名称又被隐藏。当前采用原生 `LabeledContent` 和原生菜单 `Picker`，保持标题与选择值；其他平台仍返回原来的 `Picker`。该最终组合待解锁 Mac 后复查。
2. 目录中面包屑取得焦点后，向上无法到达右上角选择操作。TV 的“选择目录”已改为原生列表首行，实际已用遥控器进入/取消选择模式；路径文字不再建立额外焦点，返回保留系统导航。
3. 选择模式中每行两个自动样式按钮共用列表行激活：一次确认同时勾选并进入下级目录。已在模拟器明确复现。TV 改为一行一个按钮，选择模式只勾选，浏览模式只进入；原生上下文菜单保留选择时浏览下级目录的能力。最终单按钮行为待复查。
4. 实际 Emby 首页的横幅只有标题/评分可见，介绍和操作被裁出区域。背景图从布局子元素移到有明确尺寸的背景层，避免图片固有尺寸撑开内容布局；工具栏改为图标标签，避免文本被截为省略号；空页面使用整行宽度。最终画面待复查。

最新 tvOS 模拟器、iOS 真机与 macOS 构建通过；聚合媒体库离线检查通过。检查脚本的 Swift 模块缓存改为本次测试独立目录，解决 `/tmp` 与 `/private/tmp` 指向同一缓存导致模块重复加载的问题。

当前运行阻塞：Mac 锁屏，电脑操作工具要求用户解锁后才能继续。WebDAV 已浏览到 `115 / 媒体库`，确认存在电影与电视剧目录，但导入确认尚未完成。尚未完成全部页面、详情、播放和遥控器流程验收，不应将这些条目记为已修复验收。

## 参考与差异

- [Apple focusSection](https://developer.apple.com/documentation/swiftui/view/focussection())：沿用系统焦点搜索，按栏目和控制区组织焦点，不额外接管每一帧手势。
- [Apple onExitCommand](https://developer.apple.com/documentation/swiftui/view/onexitcommand(perform:))：用平台返回事件管理播放器内部层级。
- [Swiftfin tvOS PlaybackControls](https://github.com/jellyfin/Swiftfin/blob/main/Swiftfin%20tvOS/Views/VideoPlayer/PlaybackControls/PlaybackControls.swift)：研究其分离播放控件显示、启用状态及焦点区域的结构。Lucent 保留自身 PlaybackSession 和 SwiftUI 原生焦点，没有引入其 FocusCoordinator 或复制源码。Swiftfin 为 MPL-2.0；本轮仅参考设计，无新增第三方依赖。
